# Music Impact Web Zine

A personal web zine exploring 10 albums that have had the biggest impact on my life, featuring interactive elements, album information, and audio samples.

## 🌐 How to Share This Website

### Option 1: GitHub Pages (Recommended for Sharing)

This is the easiest way to share your website with others online!

#### Setup Instructions:

1. **Enable GitHub Pages:**
   - Go to your repository on GitHub: https://github.com/jahighshaw-tech/jahighshaw-tech-jahighshaw-tech-JacksonHighshaw_InteractivityIISp26_Project-1
   - Click on **Settings** (top right)
   - Scroll down to the **Pages** section in the left sidebar
   - Under "Source", select the **main** branch (or whichever branch has your code)
   - Click **Save**

2. **Get Your Shareable Link:**
   - After a few minutes, your site will be live!
   - Your URL will be: 
     ```
     https://jahighshaw-tech.github.io/jahighshaw-tech-jahighshaw-tech-JacksonHighshaw_InteractivityIISp26_Project-1/
     ```
   - GitHub will display this URL in the Pages settings once it's ready

3. **Share the Link:**
   - Copy the URL and share it with anyone!
   - They can view your web zine from anywhere with an internet connection
   - No login or GitHub account required for viewers

#### Updating Your Site:
- Any changes you push to the main branch will automatically update your live site
- Changes may take 1-2 minutes to appear

### Option 2: Local Viewing

If you want to view the site locally on your computer:

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/jahighshaw-tech/jahighshaw-tech-jahighshaw-tech-JacksonHighshaw_InteractivityIISp26_Project-1.git
   cd jahighshaw-tech-jahighshaw-tech-JacksonHighshaw_InteractivityIISp26_Project-1
   ```

2. **Open in your browser:**
   - Simply double-click `index.html`
   - Or right-click and choose "Open with" → your browser

3. **Using a local server** (recommended for full functionality):
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   
   # Using Node.js (if you have it installed)
   npx http-server
   ```
   Then open `http://localhost:8000` in your browser

### Option 3: Other Hosting Services

You can also deploy this site to:
- **Netlify**: Drag and drop your folder at https://app.netlify.com/drop
- **Vercel**: Import from GitHub at https://vercel.com/new
- **Surge**: Run `npx surge` in your project directory
